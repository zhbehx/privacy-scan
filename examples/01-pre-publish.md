# 案例：一条「只是分享收快递体验」的帖子

## 用户想发的内容

> 📦 今天收到的快递太慢了，客服电话 13812345678，我在北京市朝阳区建国路88号3号楼502室等了两天。
> 我把订单截图发一下，单号 SF1234567890123。
> 对了，加我微信：zhangsan_2024 一起拼单。
> 身份证 110105199003074512 要寄过去才能改地址，太麻烦了。

标题打算写《被快递气到的一天》。

## 脚本扫描结果（实测）

```
$ python scripts/privacy_scan.py draft.md --explain

命中 6 处：必删 2 · 建议删 3 · 看情况 1
结论：建议不发：有必删项，改完再发

  [必删] 完整手机号  第 1 行  13*******78（11 字符）
       风险：可被用于骚扰、撞库、社工
       处理：删掉或改为「私信我」；确需保留只留后四位
  [必删] 身份证号  第 4 行  11**************12（18 字符）
       风险：可直接用于实名认证与开户
       处理：整段删掉，不要保留任何位数
  [建议删] 详细地址  第 1 行  我在**********8号
       风险：可定位到具体位置
       处理：保留到区，删掉街道与门牌
  [建议删] 门牌/房号  第 1 行  3号***2室（7 字符）
       风险：结合小区名可精确定位
       处理：删掉房号
  [建议删] 快递单号  第 2 行  SF***********23
       风险：可反查收件人手机尾号与大致地址
       处理：整块涂黑
  [看情况] 微信号  第 3 行  微信************24
       风险：公开平台留微信可能违规且被爬
       处理：改为「私信」
```

## 逐项分析：哪几处是真的危险

### 1. 身份证号 —— 最高危，必须删

这不是「隐私偏好」问题。身份证号 + 姓名可以用于：

- 注册某些平台的实名认证
- 配合手机号做社工攻击（冒充客服）
- 部分小额信贷的风险审核

**任何情况下都不要发。** 而且这句「要寄过去才能改地址」还暴露了你的操作流程，等于告诉别人怎么骗你。

### 2. 手机号 —— 高危，但很多人觉得无所谓

「反正我手机号到处都有」是常见想法。但这条帖子的组合是：

> 手机号 + 详细到门牌的家庭地址 + 微信号 + 你连续两天在家等快递

这不是「一个手机号」，这是**「这个人现在家里有快递没取，且我能联系上他」**。

### 3. 详细地址 + 房号 —— 组合起来才危险

单看「北京市朝阳区」没问题。单看「3号楼502室」也没问题。

但这两个 + 快递单号 = **能推算出具体小区、楼栋、房号、以及你什么时候不在家**。

### 4. 快递单号 —— 最容易被忽略

快递单号能查到：收件人手机号后四位、大致投递地址、当前状态。配合帖子内容，等于把「我家的快递还堆在门口」公开广播。

### 5. 微信号 —— 平台规则问题

小红书、抖音等平台明确限制导流到微信。这不只是隐私问题，还可能限流或删帖。

>
> 我们小区快递柜满了，只能放驿站。驿站离我家 1.2 公里，来回一趟 40 分钟。
> 最离谱的是客服说「可以申请送货上门」，但要先证明我在家——怎么证明？拍门牌号？
>
> 后来我想了个办法：把取件码发给邻居，请他帮忙带一下。邻居说他也这么干。
>
> 所以想问问大家：你们小区的快递现在都怎么拿的？有没有靠谱的解决办法？

改动说明：

| 原内容 | 处理 | 为什么 |
| --- | --- | --- |
| 客服电话 13812345678 | 删掉 | 与内容无关（而且这是对方号码，公开也不合适） |

## 还要检查的：那张订单截图

文本改干净了，但用户原本打算「发订单截图」。按清单过一遍：

| 检查项 | 这张截图里有什么 | 处理 |
| --- | --- | --- |
| 顶部状态栏 | 有具体时间（凌晨 1:47） | 裁掉 |
| 订单号 | 完整显示 | 整块涂黑 |
| 收件地址 | 完整门牌 | 整块涂黑 |
| 收件人姓名 | 真名 | 整块涂黑 |
| 手机号 | 中间四位打码，但前后可见 | **整块涂黑**（前后可见已足够推断） |
| 商品信息 | 无敏感 | 保留 |
| 头像 | 无 | — |

**结论：这张截图不该发。** 它需要涂黑 4 个区域，涂完之后几乎没有信息量了——不如不发。

## 这个案例说明了什么

1. **真正的泄露是组合，不是单项。** 手机号本身不致命，手机号 + 门牌 + 「我在家等两天」就致命。
2. **用数字替代细节，比打码更聪明。** 「1.2 公里、40 分钟」比「建国路 88 号」信息量更大、风险为零。
3. **截图比文本危险得多。** 文本你能逐字检查，截图里藏着 10 个你没注意的地方。
4. **打码要整块涂黑。** 「只遮中间四位」在截图分享场景里等于没遮。
